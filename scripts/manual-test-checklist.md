# 手動テストチェックリスト 「テストは最後にまとめてやる」

`npx expo start --web --port 8081 --clear` でサーバーを起動し、ブラウザ（http://localhost:8081）で以下を上から順に確認する。
`scripts/e2e-smoke.cjs` の自動チェックと同じシナリオを、実際に手で操作して目視確認するためのもの。

## 1. 基本の画面遷移
- [ ] Profile画面を開く → 年齢欄が空欄（前回入力が残っていない）
- [ ] 年齢だけ入力して「サービスを検索する」→ Results画面が表示され、クラッシュしない
- [ ] いずれかのカードの「詳細を見る」→ Detail画面に遷移し、内容が表示される
- [ ] 左上の「←」で戻る → Results画面に正しく戻る
- [ ] 「チャットで詳しく調べる」→ Chat画面が開き、プロフィール情報を含む挨拶が出る
- [ ] 区を選択した状態で「人ごとに見る」→「防災情報」→ 防災情報画面が表示される

## 2. 高齢者家族の表示分離
プロフィール：本人40歳・既婚・家族と同居＋高齢者を追加（68歳・続柄「親」）
- [ ] 検索結果に「本人向けサービス」と「親（68歳）向けサービス」が別々の見出しで出る
- [ ] 「親（68歳）向け」に、いきいき支援センターや介護保険サービスなど高齢者向け項目が入っている
- [ ] 「本人向け」に高齢者向け項目が紛れ込んでいない

## 3. 子ども複数人の表示分離
プロフィール：本人38歳・離婚/別居＋子どもを2人追加（6歳・15歳）
- [ ] 「1人目のお子さま（6歳）向けサービス」「2人目のお子さま（15歳）向けサービス」が別々に出る
- [ ] 「人ごとに見る」モードでも本人・子どもがタブで分かれている

## 4. 成人家族（ひきこもり）の表示分離
プロフィール：本人50歳・既婚・家族と同居＋成人家族を追加（30歳・続柄「兄弟姉妹」・タグ「ひきこもり・不登校」）
- [ ] 「兄弟姉妹（30歳）向けサービス」に「なごや若者サポートステーション」等が出る
- [ ] 「本人向けサービス」にはひきこもり関連の項目が**出ない**
- [ ] 「本人向けサービス」に特定健康診査・がん検診・市民税減税など、本人の年齢・一般属性で決まる項目は**消えずに残っている**
  （※ここらぼは「困りごと・タグ選択時のみ表示」の仕様のため、本人にタグ・困りごとがないこのプロフィールでは出なくて正しい）

## 5. 成人家族（タグなし）に誤表示がないか
プロフィール：本人55歳・既婚・家族と同居・本人は「身体障害（手帳あり）」にチェック＋成人家族を追加（28歳・続柄「成人の子」・タグは何も付けない）
- [ ] 「本人向けサービス」に「障害者向け交通料金等の軽減」が出る（本人は手帳ありのため正しい）
- [ ] 「成人の子（28歳）向けサービス」には「障害者向け交通料金等の軽減」が**出ない**（タグなしのため）
- [ ] 上記で本人の代わりに「困りごと」で「交通・移動のこと」にチェックした場合も、タグなしの成人の子には同じ項目が**出ない**

## 6. 防災情報：乳幼児がいる世帯
プロフィール：区を選択・本人32歳＋子どもを追加（3歳）
- [ ] 「人ごとに見る」→「防災情報」で、「要配慮者の方がいる世帯への注意」カードが表示される

## 7. 異常系入力
- [ ] 年齢を空欄のまま検索 → クラッシュしない、それなりの件数が出る
- [ ] 年齢に「999」を入力して検索 → クラッシュしない

## 8. チャットで詳しく調べる（AIチャット相談）
プロフィール：本人32歳・離婚/別居＋子どもを1人追加（3歳）・「ひとり親」の状態で検索

- [ ] Results画面右下の「チャットで詳しく調べる」→ Chat画面に遷移し、クラッシュしない
- [ ] 最初のボットメッセージ（挨拶）にこのプロフィールの内容（年齢・ひとり親・子ども1人（3歳）等）が反映されている
- [ ] 挨拶の下に「おすすめの質問」チップが表示される（子どもがいる＋ひとり親のプロフィールなので「子どもの医療費助成はある？」「ひとり親への支援はある？」等、プロフィールに沿った内容になっている）
- [ ] チップの1つをタップ → タップ内容がそのまま質問として送信され、入力欄を経由せず自動で吹き出しが追加される
- [ ] 送信後、ローディング表示（「...」やスピナー）が出て、その後AIからの返信が吹き出しで表示される
- [ ] 返信内容に名古屋市の具体的なサービス名・URLなど、このプロフィールに関係しそうな情報が含まれている（AIの応答なので厳密な一致は不要、支離滅裂でなければOK）
- [ ] 返信中（ローディング中）は入力欄・送信ボタンが操作できない（連打しても二重送信されない）
- [ ] 入力欄が空のまま送信ボタンを押しても送信されない（ボタンが非活性になっている）
- [ ] 自由入力欄に質問を自分で入力して送信 → 送信後に入力欄が空になり、会話が上に積み上がっていく
- [ ] 続けて2〜3回やり取りしても、前の会話内容を踏まえた応答になっている（履歴が保持されている）
- [ ] 左上の「←」で戻る → Results画面に戻り、検索結果（プロフィール・件数）が保持されたままになっている

### 8-1. プロフィール未入力の場合
プロフィール：何も入力せず「サービスを検索する」→ Chat画面へ

- [ ] 挨拶メッセージのプロフィール欄が「プロフィール未入力」等、空欄でもクラッシュしない表示になる
- [ ] おすすめチップが汎用的な内容（「申請できるサービスを教えて」等）になる（該当する属性がないため）

### 8-2. 異常系
- [ ] 質問文に絵文字や記号だけを入力して送信してもクラッシュしない
- [ ] （可能であれば）通信を切断した状態やAPIキーが無効な状態で送信 → 「エラー」を含むメッセージが吹き出しで表示され、アプリごと落ちない

## 9. 自由に触ってみる
- [ ] 上記以外の組み合わせ（高齢者2人＋成人家族2人＋子ども2人、など）で、コンソールエラーが出ないか
- [ ] カテゴリフィルター（救急医療・子育て・高齢者…）を一通りクリックしてみて表示が崩れないか

何か期待と違う挙動があれば、その時のプロフィール入力内容（年齢・タグ・困りごと等）をメモしておくと調査しやすい。
